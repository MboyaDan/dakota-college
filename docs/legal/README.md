## How to use these

1. The college and its lawyer edit these files, filling every `[TO CONFIRM: …]`.
2. When approved, a Content Editor creates a Page in the staff portal with the address in the table (for example `privacy`), pastes the approved text, and a Registrar or Principal publishes it. Nothing reaches production until then.
3. If the platform changes what data it collects or which services it uses, update the notice before the change goes live.

The development seed shows these drafts on local sites, marked "(Sample) Draft", so the layout can be reviewed. A test keeps the seed copies identical to these files.

## Text format

Plain text, the same as the staff portal Page body: blank lines between paragraphs, `## ` at the start of a line for a heading, `- ` for a list item. No other formatting is shown.
